# MovieSorterApp (SCANFLIX)
MovieSorterApp Scans for Local Movies on your Drive and provides posters,metadata as media library

Scan your Files And Watch it like Netflix :)

Features : 

- Scan local movie folders
- Sorts Movie Easily and better Visual Display
- Automatically download movie posters and backdrops
- Movie metadata (Synopsis, Genre, Runtime, Rating, Release Date)
- Hero Banner with featured movies
- Top Rated movie section
- Recently Added category
- Fast local movie browsing
- Fast loading using local cache
- One-click playback with VLC Media Player
- Launch movies directly in fullscreen

Build With
-Winform Net 10.0
-TMDB API 
-VLC Media Player
